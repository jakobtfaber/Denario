Develop a Python program that calculates the first 10 Fibonacci numbers and presents them through a command-line interface. The program will display the Fibonacci numbers in a simple text format and provide an ASCII representation where each number is visualized as a series of asterisks corresponding to its value. Additionally, the program will prompt the user to choose how many Fibonacci numbers to display, allowing for a slight degree of interactivity while maintaining clarity and educational value without the complexity of a GUI.
